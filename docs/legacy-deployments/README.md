# Legacy & Enterprise-Specific Deployments

This directory contains documentation and contracts specific to custom enterprise deployments of Genesis Agents.

## Contents

- **FINANCE-TOOL-CONTRACTS-E4L.md** — Finance tool risk classification and authorization contracts for a specific enterprise deployment (Energy 4 Life / Cato). This is a reference example of comprehensive finance-adjacent tool governance.

## White-Label vs. Enterprise

The white-label Genesis Agents marketplace (documented in `/WHITE_LABEL.md`) provides 24 general-purpose agents. Enterprise customers may require:

- Custom agent skill bundles
- Industry-specific authorization frameworks
- Dedicated deployment profiles with specialized security controls
- Custom tool risk classifications
- Integration with specific accounting/ERP systems

Documentation for such deployments is maintained here separately from the core white-label product.

**Note:** If you're implementing a custom deployment, use these documents as reference templates but adapt them for your specific requirements. Do not copy deployment-specific identifiers, legal entity names, or system-of-record details.
